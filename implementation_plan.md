# NCPOR Polar Command Center Dashboard

Building a full Vite + React + Tailwind CSS dashboard with the following structure.

## Components
- Header (Network Status, UTC Clock, User Profile)
- Sidebar (Collapsible Navigation)
- Dashboard Main View:
  - Live Operational Map placeholder
  - Inventory Bar Chart (Recharts)
  - Active Deployments Table
  - Cargo En Route Timeline
- Skeleton Loaders
- All dummy data structured for easy DB swap
